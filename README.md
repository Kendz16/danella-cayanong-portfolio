# Danella Cayanong Portfolio

A React and Vite portfolio for Danella Cayanong.

The inquiry form submits to the Formspree form configured in
`src/components/InquiryFormSection.tsx`. Set and verify the notification
recipient in the Formspree dashboard for that form.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local URL when the development server starts.

## Validate and build

```sh
npm run lint
npm run build
```

To serve the production build locally, run `npm run preview` after building.
